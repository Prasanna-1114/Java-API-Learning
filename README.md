# Java API Learning

This repository contains my daily API learning journey using Java and Spring Boot.

## Goal

Learn APIs from beginner to advanced level with:

* API fundamentals
* HTTP
* REST APIs
* Postman
* Java
* Spring Boot
* MySQL
* Spring Data JPA
* Validation
* Exception Handling
* Spring Security
* JWT
* Swagger / OpenAPI
* Testing
* Advanced API concepts
* Microservices

## Learning Method

For every topic:

1. Understand the concept
2. Learn why it is used
3. Understand real-world usage
4. Write Java / Spring Boot examples
5. Test APIs
6. Complete practice tasks
7. Push daily work to GitHub
